# 🎮 Gaming

A collection of lightweight tools, utilities and applications for gamers, game server administrators and gaming communities.

This repository serves as a home for small standalone projects that solve practical problems around gaming, dedicated servers and automation.

Each project is designed to be as simple, portable and easy to use as possible.

- Minecraft Java & Bedrock

- Factorio
- Valheim
- ARK
- Generic servers
- Live console
- Automatic backups

# Design Philosophy

All projects inside this repository follow the same principles.

- Portable
- Lightweight
- No unnecessary dependencies
- Easy to configure
- Open source
- JSON configuration where possible
- Simple user interface
- Easy to maintain

The goal is to create useful tools that simply work without requiring complex installation or administration.
